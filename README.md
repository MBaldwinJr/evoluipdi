# Growth Navigator

Aqui está um prompt altamente estratégico e completo, baseado no conteúdo do material que você enviou (ciclo contínuo de performance, conexão entre feedback e PDI, protagonismo do colaborador e modelo 70-20-10) — pronto para você usar em ferramentas como Lovable, Bubble, FlutterFlow, Firebase Studio ou até IA de código:

🔥 PROMPT PODEROSO — SISTEMA DE GESTÃO E DESENVOLVIMENTO DE EQUIPES

Crie um sistema completo de gestão de pessoas e desenvolvimento de colaboradores, focado em performance contínua, feedback estruturado e construção de Planos de Desenvolvimento Individual (PDI), utilizando tecnologia como apoio estratégico (não substituindo a interação humana).

🎯 OBJETIVO DO SISTEMA

Desenvolver uma plataforma inteligente que transforme avaliação de desempenho em crescimento real, conectando dados, feedbacks e ações práticas em um ciclo contínuo de evolução dos colaboradores.

🧠 PRINCÍPIOS DO SISTEMA (BASE CONCEITUAL)

O sistema deve ser construído com base nos seguintes pilares:

Performance como ciclo contínuo (não evento isolado)

Feedback como insumo → PDI como plano de ação

Clareza de expectativas (baseado em cargos e funções)

Desenvolvimento individual (não genérico)

Protagonismo do colaborador + apoio do gestor + estrutura do RH

Uso da tecnologia como facilitador estratégico

🏗️ MÓDULOS DO SISTEMA

1. 📋 Gestão de Cargos e RCF (Responsabilidades, Competências e Funções)

Cadastro completo de cargos

Definição clara de:

Responsabilidades

Competências técnicas e comportamentais

Indicadores de desempenho

Associação com setores

Base para avaliações e entrevistas

2. 👤 Gestão de Colaboradores

Perfil completo do colaborador

Histórico de:

Cargos ocupados

Evolução na empresa

Avaliações anteriores

PDIs passados

Objetivos de carreira

3. 🎤 Módulo de Entrevistas (Inicial, Periódica e de Avaliação)

Entrevistas personalizadas por setor/cargo

Roteiros dinâmicos baseados no RCF

Registro completo de respostas

Classificação automática de desempenho

Histórico de entrevistas por colaborador

4. 📊 Avaliação de Desempenho Inteligente

Comparação entre:

Expectativa do cargo vs desempenho atual

Classificação:

Abaixo / Dentro / Acima do esperado

Input de feedback estruturado com base em:

Fatos concretos

Comportamentos observáveis

Evitar feedback genérico

5. 💬 Sistema de Feedback Contínuo

Registro de feedbacks informais (dia a dia)

Feedback formal estruturado

Regras:

Intenção (ajudar)

Clareza (exemplos reais)

Compromisso (próximos passos)

Linha do tempo de feedbacks por colaborador

6. 🧩 Identificação de Gaps Automatizada

Análise automática entre:

Competências exigidas vs atuais

Sugestão de gaps prioritários

Aplicação de lógica como:

Técnica dos 5 porquês (raiz do problema)

7. 🚀 PDI (Plano de Desenvolvimento Individual)

Criação estruturada em 4 etapas:

Definição de objetivo (curto, médio ou longo prazo)

Identificação de gaps

Transformação em pontos de desenvolvimento mensuráveis

Plano de ação prático

8. 📈 Aplicação do Modelo 70-20-10

Para cada PDI, o sistema deve sugerir automaticamente:

70% (Prática):

Atividades no dia a dia

Desafios reais no trabalho

20% (Troca):

Mentorias

Shadowing

Aprendizado com colegas

10% (Formal):

Cursos

Treinamentos

Leituras

9. 🤖 Motor de Sugestões Inteligentes

Sugestões automáticas de:

Ações de desenvolvimento

Melhorias comportamentais

Ajustes de performance

Baseado em:

Gaps identificados

Histórico do colaborador

Perfil do cargo

10. 📅 Acompanhamento e Evolução

Dashboard com:

Evolução do colaborador

Status do PDI

Indicadores de desenvolvimento

Check-ins periódicos

Alertas automáticos para gestores

11. 🧑‍🤝‍🧑 Papéis no Sistema

Colaborador:

Propor seu próprio PDI

Acompanhar evolução

Registrar aprendizados

Gestor:

Validar e orientar PDIs

Dar feedback contínuo

Acompanhar evolução

RH:

Criar estrutura e metodologia

Monitorar consistência do processo

Garantir uso estratégico do sistema

12. 📊 Relatórios e Inteligência de Dados

Relatórios de:

Performance por equipe

Principais gaps da empresa

Evolução de colaboradores

Insights para decisões estratégicas

🎨 DIFERENCIAIS DO SISTEMA

Interface simples e intuitiva

Visualização em formato de timeline (histórico completo)

Sistema “vivo” (não apenas formulários)

Foco em ação prática, não burocracia

Integração entre todos os módulos

IA como apoio na construção de feedbacks e PDIs

⚙️ TECNOLOGIAS SUGERIDAS

Frontend: React + Tailwind

Backend: Firebase ou Node.js

Banco de dados: Firestore

IA: OpenAI API

Versão PWA (instalável)

💡 RESULTADO ESPERADO

Um sistema que:

Evita PDIs esquecidos

Torna feedbacks mais claros e acionáveis

Cria cultura de desenvolvimento contínuo

Aumenta engajamento e performance

Transforma RH em área estratégica
